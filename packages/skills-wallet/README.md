# Skills Wallet

This package implements a simple skills wallet carousel to display personal skills.

## How to View

1. Ensure your browser supports the experimental HTML `<carousel>` element. You may need to enable a feature flag (e.g., `#enable-experimental-web-platform-features` in Chrome).
2. Navigate to the `packages/skills-wallet` directory.
3. Open the `index.html` file in your web browser.

## Contents
- `index.html`: The main HTML file containing the carousel structure.
- `style.css`: Styles for the page and carousel.
- `script.js`: Placeholder for JavaScript functionality (currently minimal).
